# Python Word Scramble

A simple terminal-based word scramble game built in Python.

This is one of my first Python projects, created while learning Python fundamentals through project-based learning.

## Features

- Random word selection and scrambling
- Three difficulty levels: Easy, Normal and Hard
- Different scoring based on difficulty
- Input validation
- Multiple game rounds
- Total score tracking
- Win/loss statistics
- Win rate calculation

## What I Practiced

- Functions
- Function parameters and return values
- Multiple return values
- Lists and tuples
- Dictionaries and nested dictionaries
- Loops and conditionals
- Input validation
- String methods
- Variable scope
- Argument unpacking
- Python's `random` module

## How to Run

Make sure Python is installed.

Clone the repository and run:

```bash
python3 main.py
```

## Difficulty Levels

| Difficulty | Lives | Starting Points |
|------------|------:|----------------:|
| Easy | 5 | 50 |
| Normal | 3 | 100 |
| Hard | 1 | 200 |
